# クチコミブースト（Kuchikomi Boost）

個人店（整体・美容・士業・教室など）向けの **Google口コミ自動収集ツール** のMVPです。

QR/リンクを配るだけで、満足したお客様を **Googleクチコミ投稿へスムーズに誘導**。
不満は **店内フィードバックとして非公開で受け取り**、改善に活かせます。

📄 企画・市場分析・収益試算は [`docs/企画書.md`](docs/企画書.md) を参照してください。

---

## 特長

- **リンク1本で口コミ依頼を仕組み化**（レジ横・名刺・LINEで配布）
- **スマート導線**：高評価 → Google投稿画面へ誘導 / 低評価 → 非公開フィードバックへ
- **ダッシュボード**：評価件数・平均★・Google誘導数・改善フィードバックを可視化
- **運用モード切替**：レビューゲーティング禁止ポリシーに配慮した「コンプラ重視」モードを用意

> ⚠️ Googleは「レビューゲーティング」を禁止しています。詳細は企画書のコンプライアンス節を参照。

## 動かし方

依存ライブラリはありません（Node.js 18+ の標準モジュールのみ）。

```bash
npm start          # http://localhost:3000 で起動（PORT 環境変数で変更可）
```

1. ブラウザで `http://localhost:3000/admin` を開く
2. 「店舗を新規登録」から店名・Googleクチコミ投稿URLを登録
3. 発行された依頼リンク `/r/{slug}` をお客様へ
4. ダッシュボードで結果を確認

## 構成

```
server.js        HTTPサーバ・ルーティング（標準モジュールのみ）
lib/store.js     JSONファイルストア（将来 SQLite/PostgreSQL へ移行しやすい構造）
lib/views.js     画面（サーバサイドHTML生成）
public/style.css スタイル
data/db.json     データ（自動生成・gitignore対象）
docs/企画書.md    市場分析・収益試算・ロードマップ
```
