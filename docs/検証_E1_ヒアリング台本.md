> 目的：整体・接骨院 **5店**に話を聞き、「口コミ収集にお金を払う意思があるか」「本ツールに価値を感じるか」を確かめる。
> 成功ライン：**5店中3店が前向き**（「月¥1,980なら使ってみたい」）。
> 位置づけ：[企画書](企画書.md) 第13章 E1/E5。所要：1店あたり15〜20分。

## 0. 準備するもの

- 動くデモ（手元PCで `start.sh`/`start.bat` 起動、または本番URL）
- デモ用に「その店の名前」で店舗を1件登録しておく（リアルに見える）
- このメモ用紙（下の記録シート）

## 1. 進め方（時間配分）

1. あいさつ・主旨説明（1分）
2. 現状ヒアリング（5分）← **売り込まない。聞く。**
3. デモを見せる（5分）
4. 価格・利用意思の確認（3分）
5. お礼・次アクション（1分）

---

## 2. トークスクリプト

### あいさつ
「お忙しいところすみません。整体院さん向けに、**Googleの口コミを増やすお手伝いをするツール**を作っていて、現場の声を伺いたくて来ました。売り込みではなく、率直なご意見をいただけると嬉しいです。5分だけよろしいですか？」

### 現状ヒアリング（聞くだけ・誘導しない）
- 「いま新しいお客様は、何で来られることが多いですか？（紹介／ホットペッパー／Googleマップ…）」
- 「Googleの口コミって、集客に効いてる実感はありますか？」
- 「**口コミって、今どうやってお願いしてますか？**」（声かけ／POP／特に何もしていない…）
- 「お願いするの、ちょっと**気まずい・言い忘れる**ことってありますか？」 ← 課題の核
- 「**悪い口コミがそのまま載るの**、気になりますか？」
- 「口コミやMEOの**ツールは何か使っていますか？**（あれば名前・月額・不満）」

### デモを見せる（実機）
「実際の画面でお見せします。」
1. **お客様側**：QR/リンクを開く → ★を選ぶだけ
2. **★5を選ぶ** → そのまま**Google投稿画面へ**誘導される様子
3. **★2を選ぶ** → 公開されず**店内向けフィードバック**に回る様子（「悪い評価が直接表に出にくい」）
4. **オーナー側**：QRを印刷してレジ横に置ける／集計・フィードバックが見える

ひとこと：「やることは**QRを置いて、満足したお客様にそっと促すだけ**。設定は数分です。」

### 価格・利用意思の確認（重要）
- 「これ、**月いくらなら使ってみたいと思いますか？**」（先に相手の口から金額を）
- 「**月1,980円**だったらどうですか？高い／安い／妥当？」
- 「もし**無料で試せる**なら、まず置いてみてもいいと思いますか？」
- （前向きなら）「**実際に1か月、無料で試してみませんか？**」← E2パイロットへ接続

### お礼・次アクション
「ありがとうございます。すごく参考になりました。」（試用OKなら日程・QR設置の段取り）

## 4. 集計（5店終わったら）

- 前向き（◎＋○のうち試用OK）が **3店以上 → E2（パイロット）へ**
- 価値(デモ)は刺さるが価格が弱い → 価格・無料枠を見直して再検証（Pivot）
- 「気まずい・言い忘れる」課題がほぼ無い → 刺さる業種を変える検討

> ⚠️ ヒアリングは**売り込みでなく学習**が目的。否定的な声ほど価値がある。インセンティブ（割引と引換の口コミ依頼）は景表法リスクがあるため案内しない。
