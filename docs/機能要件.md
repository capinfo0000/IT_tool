# クチコミブースト 機能要件

> 個人店向け Google口コミ自動収集ツールの機能要件。`実装済み` は現行MVPで動作するもの、`次フェーズ` は未実装の予定。
> 関連：[企画書](企画書.md) / [README](../README.md)

---

## 1. お客様（来店客）向け機能 ※ログイン不要

- **星評価ページ**（`/r/{店舗スラッグ}`）：★1〜5をタップで選ぶだけのシンプル画面 `実装済み`
- **スマート導線（自動振り分け）**：選んだ★としきい値に応じて遷移先を自動で出し分け `実装済み`
  - しきい値以上 → **Googleクチコミ投稿画面へ誘導**（リダイレクト）
  - しきい値未満 → **非公開フィードバックフォーム**へ
- **非公開フィードバック送信**：コメント＋連絡先（任意）を店舗だけに送信（公開されない） `実装済み`
- **完了画面**：投稿後のお礼表示 `実装済み`

## 2. 店舗管理（運用者）向け機能 ※要ログイン

- **店舗の新規登録**：店名／Googleクチコミ投稿URL／しきい値／運用モードを設定 `実装済み`
- **店舗設定の編集**：登録後にGoogle URL・しきい値・運用モードを変更可能 `実装済み`
- **店舗一覧**：登録済み店舗と各依頼リンクの表示 `実装済み`
- **ダッシュボード（店舗ごと）** `実装済み`
  - **依頼リンク**の表示（コピーして配布）
  - **QRコード**の表示＋**印刷**（レジ横POP用）
  - **KPI集計**：総評価数／平均★／Google誘導数／非公開回収数
  - **非公開フィードバック一覧**：評価・コメント・連絡先・日時

## 3. 運用モード（コンプライアンス対応）

- **改善フォーカスモード**：低評価を非公開回収（※レビューゲーティングに該当し得る） `実装済み`
- **コンプライアンス重視モード**：全員にGoogle投稿を案内（ゲーティングしない／既定推奨） `実装済み`
- **Google誘導のしきい値設定**：★3以上／★4以上／★5のみ から選択 `実装済み`

## 4. 認証・セキュリティ

- **管理画面のパスワードログイン**（セッション管理） `実装済み`
- 公開ページ（評価）は認証不要、**管理・ダッシュボードは認証必須**（非公開フィードバックの漏洩防止） `実装済み`
- 入力のHTMLエスケープ（XSS対策） `実装済み`
- SQLはプリペアドステートメント（SQLインジェクション対策） `実装済み`

## 5. データ・技術要件

- **PHP 8（ローカルは7.4でも動作）+ MySQL** 構成（コアサーバーV2想定） `実装済み`
- **PDOでDB抽象化**：本番=MySQL／ローカル=SQLite を同一コードで稼働 `実装済み`
- テーブル（店舗／評価ログ／フィードバック）は**初回アクセス時に自動生成** `実装済み`
- 共有レンタルサーバにそのまま載る（常駐プロセス不要、`.htaccess`ルーティング） `実装済み`
- 設定は `src/config.php`（DB接続・管理パスワード）に集約 `実装済み`

## 画面とルーティング対応表

| 画面 | メソッド/パス | 認証 |
|---|---|---|
| トップ | `GET /` | 不要 |
| ログイン | `GET /login` / `POST /login` | 不要 |
| ログアウト | `GET /logout` | - |
| 店舗一覧（管理） | `GET /admin` | 必須 |
| 店舗登録 | `POST /admin/business` | 必須 |
| 店舗ダッシュボード | `GET /admin/business/{id}` | 必須 |
| 店舗設定の更新 | `POST /admin/business/{id}` | 必須 |
| 評価ページ（顧客） | `GET /r/{slug}` | 不要 |
| 評価送信＋導線 | `POST /r/{slug}` | 不要 |
| 非公開フィードバック送信 | `POST /r/{slug}/feedback` | 不要 |
