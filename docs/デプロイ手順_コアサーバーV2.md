# デプロイ手順：コアサーバー V2

> クチコミブースト（PHP + MySQL）をコアサーバーV2に公開する手順。所要：30〜60分。
> 構成：公開ディレクトリ `public_html` にWebファイル、その**一つ上の階層**に `src`（プログラム）を置く。

---

## 0. 事前に用意するもの
- コアサーバーV2の契約（CORE-X 等）とコントロールパネルのログイン
- FTP情報 または ファイルマネージャー
- 配布ZIP `kuchikomi-boost-deploy.zip`（本リポジトリから生成）

## 1. PHPのバージョンを8系にする
コントロールパネル →「PHPの設定」→ 対象ドメインの**PHPを 8.x** に設定。

## 2. MySQLデータベースを作成
コントロールパネル →「データベース(MySQL)」→ 新規作成。
- DB名・ユーザー名・パスワード・ホスト名（例 `mysqlXXX.coreserver.jp` または `localhost`）を控える。
- ※テーブルは初回アクセス時に**自動生成**されるので、SQLの実行は不要。

## 3. config.php を編集
ZIP内の `src/config.php` をテキストエディタで開き、次を設定：
```php
'admin_password' => 'ここを推測されない強いパスワードに',
'driver'         => 'mysql',
'mysql' => [
    'host'    => '（手順2のホスト名）',
    'dbname'  => '（DB名）',
    'user'    => '（DBユーザー）',
    'pass'    => '（DBパスワード）',
    'charset' => 'utf8mb4',
],
```

## 4. ファイルを配置（ここが肝）
サーバの構成は「ホーム > public_html（公開領域）」です。次のように置きます：

```
（アカウントのホーム）
├── public_html/        ← ZIPの public_html/ の中身を入れる
│     ├── index.php
│     ├── .htaccess
│     └── style.css
└── src/                ← ZIPの src/ をそのまま置く（public_htmlの“外”）
      ├── db.php
      ├── views.php
      └── config.php
```
- `public_html` の**中身**（index.php 等）を公開ディレクトリへアップロード。
- `src` フォルダは **public_html と同じ階層（一つ上）** に置く。
- ※ `index.php` は `../src` を参照するため、この位置関係が重要です。

> サブディレクトリ（例 `public_html/review/`）に置く場合は、`src` をその一つ上（`public_html/`）に置けばOK。`.htaccess` のルーティングも相対で動きます。

## 5. 動作確認
- ブラウザで `https://（あなたのドメイン）/` → トップが表示されればOK。
- `https://（ドメイン）/admin` → 手順3で決めたパスワードでログイン。
- 「店舗を新規登録」→ 実在店舗の**本物のGoogleクチコミ投稿URL**を登録（下記）。

## 6. 本物のGoogleクチコミ投稿URLの取り方
- Googleビジネスプロフィール →「クチコミ」→「クチコミを増やす / リンクを共有」から
  `https://g.page/r/XXXXXXXX/review` のような**クチコミ用リンク**をコピーして店舗設定に貼る。
- これを入れると、高評価のお客様が**実際にGoogleマップへ投稿**できます（デモのダミーURLでは反映されません）。

## 7. 公開後すぐの設定
- 管理画面の店舗ごとに：しきい値・運用モード（既定＝コンプラ重視推奨）・QRのPOP印刷。
- レジ横にPOPを設置し、会計時に「QRから30秒で…」と声かけ（[E0/E1](検証_E1_ヒアリング台本.md) 参照）。

## トラブル時
- 500エラー → `src/config.php` のDB情報を再確認。PHPが8系か確認。
- 403/404 → `.htaccess` が有効か（LiteSpeedは通常有効）。`public_html` 直下に `index.php` があるか。
- 文字化け → DBのcharsetが `utf8mb4` か確認。
- ログインできない → `admin_password` の値を確認（前後の空白に注意）。

## セキュリティ
- `admin_password` は必ず推測されない値に。
- `src/` は公開ディレクトリの外に置く（DB情報を含む `config.php` を守るため）。
